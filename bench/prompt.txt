Read the text below, then write a detailed summary of it for an engineer who has never heard of the project. Use plain sentences.

Celaut is a way to run programs that anyone can check. A service is packed into a sealed image whose identifier is the hash of its content, so two people who hold the same identifier hold the same program. A node is a computer that runs such services in small virtual machines. A client asks a node to start a service, pays the node for the memory, the processor time and the disk that the instance holds, and talks to the instance through ports that the service declares. A node that has no room for a service can give the work to another node, a peer, and pay that peer. The client does not need to know where the instance runs. Each node keeps a ledger of what it charged, signs a statement of each account, and scores the peers that charge more than they quoted. A service can start other services, its children, and fund them from its own balance. The children of a service can only be reached by their parent, and a child gets only the networks that its parents also declare. This makes it possible to build a program out of many sealed parts that run on many machines, while the user still sees one service with one price. The weak points are the cost of moving data between the parts, the time that a new instance needs to start, and the trust that a client must give to a node it has never used before.
